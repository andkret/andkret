## 🧪 Free Labs

Not everything is behind a paywall. My [Free Labs](https://learndataengineering.com/p/free-labs) are short, hands-on projects built around real tools from the modern data stack, each one with videos, code, and architecture diagrams you can follow step by step. Some of the labs currently up:

- **Building Advanced Pipelines with Kestra on GCP** — orchestration with Kestra, Cloud Storage, BigQuery, and Pub/Sub
- **Spark Declarative Pipelines and Lakeflow Designer on Databricks** — moving from notebooks to production-ready pipelines
- **DuckDB for Data Engineers** — from local to cloud with MotherDuck
- **Python for Data Engineers** and **Docker Fundamentals**
